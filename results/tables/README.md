# Índice das tabelas numeradas

Esta pasta constitui a parte tabular do Apêndice A citado no TCC. Os arquivos TSV são resultados derivados do pipeline e devem ser lidos como dados suplementares, não como estatísticas-resumo brutas.

| Série | Conteúdo |
|---|---|
| 01–04 | Resumo dos estudos, SNPs líderes, loci e genes mapeados pelo FUMA. |
| 05–12 | Resultados MAGMA e matriz/auditoria de evidências que sustentam a priorização inicial. |
| 13–16 | Sobreposição de loci e clusters entre estudos. |
| 17–22 | Comparações histórica Jansen–Watanabe, sensibilidade OpenGWAS e tabela final Core16. |
| 23–29 | Enriquecimento GENE2FUNC e análise competitiva de conjuntos gênicos MAGMA. |
| 30–34 | Comparação com o suplemento de Watanabe e camada do GWAS Catalog. |
| 35–39 | Análise de conjuntos gênicos nos datasets complementares OpenGWAS. |
| 47–48 | Registro integrado e termos funcionais reportáveis. |
| 49–50 | Validação externa no FinnGen R13 corrigido. |
| 51–54 | Redes STRING, nós, termos funcionais e notas de interpretação. |

Os arquivos 40–46 correspondem a uma execução histórica do FinnGen anterior à correção de construção genômica/deduplicação. Não integram este release e não devem ser interpretados como evidência de validação.
